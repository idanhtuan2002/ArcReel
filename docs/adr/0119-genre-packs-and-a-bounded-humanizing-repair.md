# Genre packs and a bounded humanizing repair

Decided 2026-11-09 by the main agent under the sponsor's instruction to inherit the donors' genre, compliance and humanize skills (step 5 of the long-novel plan). Research: [long-novel and skill gaps](../research/2026-11-09-r2-donor-long-novel-and-skill-gaps.md) §3.8, §3.9 and §4(e).

1. **Genre packs are data.** Ten packs (family, mystery, horror, romance, action, fantasy, science fiction, comedy, historical, school), each with planning guidance for the outline, book plan and chapter plans, craft rules for drafting, and phrases the genre wears out. A run uses the pack an alias of which its brief's genre names, else the one its generated seed's genre names, else none (huohuo's per-genre skill directories, shenbi `genre-config`). A worn phrase used more than twice in a chapter is recorded as stylistic. huohuo's cultivation, system and officialdom genres are market categories and are not carried over.
2. **Humanizing is a bounded repair, never a gate.** A scene with at least three quoted machine-voice findings (the deterministic stock-phrase, contrast and genre-fatigue checks and the judged `ANTI_AI` audit) gets them repaired inside the chapter's review cycles, and the repair is kept only if it adds no harder defect (huohuo humanize loop). No detector score gates a story: huohuo's 39 % target was tuned to its own detector, and a model judging its own family's text is biased (huohuo `NM:64-68`).
3. **Compliance** is ADR-0117's `SAFETY` audit; a young-readers variant is held to the stricter list.
4. **Packaging** stays as it is: three to five titles, two or three blurbs and three to five selling points with quotes checked in code already match shenbi `short-packaging`; covers come from the film's thumbnail (ADR-0115).
5. **Narration by beats** (DramaClaw rewrite) is already the narration form of ADR-0114's screen adaptation (a hook line, compressed spoken sentences, a cliffhanger), so no separate mode is added.
