# Storyboards are judged for continuity against their references, by a qualified cloud judge

Decided 2026-11-13 by the main agent. Sponsor direction the same day: finishing the project targets strong/cloud models; quality is not bounded by small local models. Research: [video-quality donor mechanisms](../research/2026-11-13-video-quality-donor-mechanisms.md) §A/§F, [roadmap synthesis](../research/2026-11-13-r2-quality-roadmap-synthesis.md) gap I5, [ADR-0112](0112-automatic-media-is-checked-per-unit.md).

Before this decision the only model check of a storyboard asked whether the picture shows its narration line (ADR-0112 ranking judge, disabled because no local model qualified). Nothing checked that a character looks the same from shot to shot, that wardrobe and props carry across a cut, or that the 180° rule holds — the failures a viewer sees first. AI Video Production Editor judges each storyboard frame with the frame, its reference sheets and the previous frame, in a fixed order of checks, and turns the verdict into a prompt fix and a re-film queue; ViMax (HEAD `fd4b72e`) compares candidates against reference images.

1. **The judge** (`server/production_run/continuity_judge.py`). One request per frame with the frame, the reference sheets of the characters/location/props of the shot and the previous frame of the same scene, each named in the question. Eleven ordered checks: identity, wardrobe, props, location, lighting, screen direction, eyeline, staging, text, framing, artifacts (image-model defects are high severity). The model returns a score, issues and a prompt fix under a JSON schema; the status is computed in code: ≥ 90 aligned, 70–89 watch, < 70 drift, and any high-severity issue caps the score at 69. A transport or parse failure is no verdict; the frame is kept and the run never blocks on the judge.
2. **Qualification before use.** A launch profile may enable the judge only by pinning its model identity, `prompt_digest()` and a committed evidence file of `scripts/r2/qualify_continuity_judge.py`: at least 30 drift and 30 ok cases, drift recall ≥ 80%, false drift on ok cases ≤ 15%, unanswered ≤ 5%. Drift cases include identity swaps derived by construction (`--derive-swaps`: a character's reference replaced by another story's character). The bar targets cloud vision models (Gemini Flash-class or stronger); it is not lowered to fit a local model. Lite models are excluded by the 2026-11-03 probes (they accepted real defects).
3. **Use in MEDIA (next step, after qualification).** For each storyboard whose verdict is drift, MEDIA regenerates that storyboard once per generation with the verdict's `prompt_fix` appended to the provider prompt (a task payload addendum recorded in the storyboard's provenance; the script's `image_prompt` is not edited), re-judges, and keeps the best-scoring version; a frame still in drift after the bounded retry is recorded, not blocked. Verdicts go to `continuity.json` beside the episode's render, like `image_selection.json`. With a qualified judge, the ADR-0112 best-of-N selection may use the continuity score as its ranking.

Consequences: no run changes until a judge is qualified and pinned; the module, its prompt digest and the qualification tool exist now so qualification can run as soon as a cloud key is configured.
