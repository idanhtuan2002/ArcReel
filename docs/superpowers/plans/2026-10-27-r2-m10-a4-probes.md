# M10 A4 Bounded Probe Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Execute serially per the user's continue instruction and project budget; a fresh source review follows the completed branch.

**Goal:** Return durable, exact-input technical observations through existing M7 custody with bounded local tools.

**Architecture:** Preserve A1/A2 data contracts and A3 publication authority. A private request-bound host service prepares under PostgreSQL, executes fixed recipes through an isolated systemd/Landlock worker without an open DB transaction, and finalizes an append-only observation. Replay verifies the complete stored chain.

**Tech Stack:** Existing Python/Pydantic/SQLAlchemy/Alembic/M7; Linux Landlock ABI>=6, systemd user cgroups, pinned FFmpeg/FFprobe and VMAF3.2.1. No new Python/system dependency installation by the runtime.

**Spec:** [2026-10-27-r2-m10-a4-probes-design.md](../specs/2026-10-27-r2-m10-a4-probes-design.md)

## Global Constraints

- Base `2ce1478bef93a77c888f3fc8fe2a5eefd8a46d4c`; inherit sealed A3-P source and preserve all unowned bytes.
- canonical request <=1,048,576 bytes; all identity fields <=255 UTF-8 bytes.
- target/ref combined <=134,217,728 bytes and each <=67,108,864; caption <=262,144 bytes within that total.
- Tool budget `min(rule.max_runtime_ms,120000)` ms; output `min(rule.max_output_bytes,1048576)` bytes; group memory536,870,912, swap0, tasks32, CPUQuota100%, stop grace1s.
- Exactly three scratch inodes <=67,108,864 bytes each. No file creation by the restricted worker.
- Keep missing tool, invalid reference and policy-authorized inapplicability distinct.
- No public router, default runtime registration, production migration/deploy, provider call, Human disposition, M9 or M10-B change.

## Review Focus

- A completed probe replay after tools/media/profile move still returns its exact historical receipt, after authentication and stored-chain validation (Task5).
- A result-row write failure after actual tool execution cannot be labeled failed-before-acceptance or automatically rerun (Task5).
- An approved master's absolute host object_ref must be opened beneath the anchored project directory without accepting symlink escape (Task3).
- Silent audio/nonfinite loudness and EOF-open intervals need explicit measured states rather than fabricated zero (Task2).
- Missing effective cgroup/seccomp/Landlock support cannot cause unisolated tool fallback (Task3).
