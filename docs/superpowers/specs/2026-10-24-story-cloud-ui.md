# Story cloud selection in V2

Sponsor explicitly requests selectable, usable cloud models in the V2 web UI; the previous CLI-only delivery did not meet this. Reuse accepted backend credentials/config, shared registry, price compiler, StoryBrief role routing, AttemptSink atomic state/reservations, existing output checks and runtime qualification storage. Preserve old local brief serialization/digests and unrelated drafts. No new provider storage or speculative billing framework.

First concrete story cloud transport: Gemini AI Studio, using installed google-genai SDK with retries disabled, explicit count then generate, no fallback/tools/continuation. Registered Gemini Flash routes with exact USD per-token prices are supported; each configured route is checked from backend metadata. The UI is provider-neutral and consumes authoritative story route records. Further transports plug into this boundary; native Anthropic is not claimed. Existing general text providers remain available for their existing workflows.

Freeze a version2 cloud profile in new cloud briefs: route/config binding and exact declared price facts; set a visible user-approved USD cap. Optional new profile fields are excluded from old local serialization. At draft/start/execute and each outbound request validate route, price/profile and credentials/config binding; production-mode story qualification is distinct from generic text qualification. Every physical request uses existing durable reserve/dispatch/settle. Token ceilings and a conservative money bound (maximum frozen route input/output rates over total charged run tokens, including count operations) must hold atomically. Count requests have zero observed Gemini generation cost; treating their tokens as priced in run admission is deliberately conservative. Unknown usage/outcomes retain reservation; reported usage is never clamped. Reject truncation, missing usage, over-count margin, invalid schema and CJK. Thought tokens count as output exactly once. No SDK retry or schema re-ask inside an attempt.

UI lists backend routes for both roles, shows unavailable reasons, allows an explicit USD cap for cloud and shows it before Gate A. Do not label a metadata list as live qualification. Real configured-provider probes and browser evidence are separate from mocks. Prepare a reviewed release and normal production backup/deployment steps; never report usability from source tests alone.
