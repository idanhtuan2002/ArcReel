- Legacy artifacts without an R2 envelope keep ArcReel-native behavior.
- A malformed present R2 envelope fails closed as `BLOCKED`.
- Stored direct dependency snapshots are immutable during currency evaluation.
- Direct dependency mismatch produces `STALE`; unrelated changes do not.
- Provider/model/execution identity is excluded from semantic content currency.
- `GenerationCandidate != ApprovedMaster`.
- Failed or merely generated/unapproved candidates preserve the existing master.
- Explicit approval coordinates host version selection and ApprovedMaster metadata.
- Restart/reload preserves R2 metadata, active version and ApprovedMaster state.
- Concurrent promotions cannot leave the durable active version and ApprovedMaster mismatched.
- No parallel R2 SQL table or `.r2_artifacts.json` runtime registry was introduced.
